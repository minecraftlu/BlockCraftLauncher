# BlockCraft Launcher

BlockCraft Launcher is a Minecraft Java Edition launcher. The Windows x64 WPF release is built with C# and .NET Framework 4.8.

- [Latest releases](https://github.com/minecraftlu/BlockCraftLauncher/releases)
- [Windows WPF documentation](wpf-net48/README.md)

- [Code signing policy (SignPath Foundation application pending)](wpf-net48/docs/CODE_SIGNING_POLICY.md)
- [Privacy and network access statement](wpf-net48/docs/PRIVACY.md)

**Publisher / developer naming:** The launcher uses the developer nickname **晓银 (Xiaoyin)**. This nickname is not an Authenticode verified publisher identity. The executable has **not** yet received SignPath Foundation code signing; a future accepted signature would display **SignPath Foundation** as the certificate publisher. Do not assume a particular release is signed without checking its digital signature.

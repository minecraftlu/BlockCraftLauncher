# BlockCraft Launcher · Minecraft 皮肤 DIY 工作室（v0.9.32 候选）

> 2026-11-10。独立实现，专为 Windows C# / WPF / .NET Framework 4.8 Minecraft Java 启动器开发。**预计先在 v0.9.32 RC1 验证**，未完成真实 Windows/账号验收前不标记 Stable。

## 从哪里进入

打开启动器，进入侧边栏「管理 · 帮助工具 → 皮肤 DIY 工作室」。这是本机 WPF 页面，不打开第三方皮肤编辑网站、不要求安装浏览器插件或在线注册。

## 绘制与创作

- **64×64 PNG UV 像素画布**：精确映射玩家的头部、身体、左右手臂和左右腿，外层包含帽子、夹克、左右袖子和裤腿。
- **可切换部位、图层**：全部部位、头部、身体、右臂、左臂、右腿、左腿；基础层 / 外层 / 全部图层。只允许绘制合法 UV 区域，避免误写不使用的像素。
- **绘画工具**：颜色画笔、橡皮擦、取色器（右键也可取色）、区域油漆桶；画笔大小 1–5 像素，可缩放画布 4–12 倍；显示/隐藏像素网格和 UV 部位引导。
- **自由配色**：预设颜色、HEX（#RRGGBB / #AARRGGBB）、RGB 三色滑块以及透明度。每次鼠标拖拽作为一个撤销单位，可 Ctrl+Z 撤销、Ctrl+Y 重做。
- **模型与预览**：Steve 宽臂 4px / Alex 纤细臂 3px，正面/背面像素小人实时合成；可隐藏预览中的外层，不修改真实贴图数据。当前为 **2D 正反面纸娃娃预览**，不虚称完整可旋转 3D 模型。
- **原创起始模板**：柔和配色的原创上衣/裤子/面部，不直接捆绑或复制第三方创作者的皮肤素材；可以清空选中部位后自由重画。

## 本地导入、备份与导出

- **导入**标准现代 Java `64×64 PNG`，或旧版 `64×32 PNG`（旧版转换为 64×64 并镜像补足左右手腿）。仅允许真实 PNG，最大 4 MiB，拒绝伪装格式和不合理分辨率。
- **导出** Minecraft Java 官方可用的标准 64×64 PNG，去掉其他文件携带的图片元数据。
- **个人皮肤库**：保存为自定义名称、打开/刷新个人文件，在 `%APPDATA%\BlockCraftLauncher\Skins` 中与游戏存档和微软账号缓存分开保存。
- **自动恢复草稿**：编辑后本地延迟自动备份为隐藏的 `.blockcraft-recovery.png`，下次进入皮肤页时可选择恢复；切换到其他页面不会直接丢掉未保存编辑。正式保存成功后清除该草稿。
- **安全写入**：保存先写入临时 PNG，然后替换目标；如果替换失败，仍保留未保存/自动恢复状态。

## 可选正版 Java 皮肤上传

- 仅当用户已通过启动器完成微软正版 Minecraft Java 登录，并且用户**手动点击“上传到微软正版账号”并在对话框明确确认**，才发送 64×64 PNG。
- 只使用 Minecraft 官方 `POST https://api.minecraftservices.com/minecraft/profile/skins`，上传 `variant=classic/slim` 和 PNG 原始文件，携带 Minecraft Java 会话的 Bearer Token；不向第三方转发令牌、不把令牌写到皮肤 PNG、UI 或日志。
- 禁止重定向 Bearer Token，不后台自动上传，失败不会密集重试；401 要求重新登录，429 提示稍后手动尝试，保护正版账户。
- 成功后已向官方服务提交皮肤，更改在游戏里显示可能需要重新进入世界或等待缓存刷新。
- **离线账号 / 服务器联机的外部皮肤同步**：本地保存和导出不等于其他玩家能看到皮肤。离线皮肤服务需要相应游戏端或服务器插件支持，不会伪称本功能已覆盖。
- 操作方式参考官方说明：[Minecraft: What is a Skin?](https://www.minecraft.net/en-us/article/what-is-minecraft-skin)。

## Windows 离线自动化验收

- 启动器 CLI `--skin-selftest`：合法 UV/基础外层隔离、绘制/填充、撤销/重做、Steve/Alex 预览、PNG 保存导入、旧 64×32 自动转换、坏格式和路径穿越拒绝。
- 本地模拟官方皮肤上传请求而不联网，检查只向官方 HTTPS API 使用 POST，严格 `multipart/form-data` 包含模型和完整 PNG，离线/无 token/假 PNG 被拒绝。
- WPF `--ui-layout-selftest`：经过真实皮肤 DIY 页面，验证颜色/绘制/UV 外层、PNG 视图、Undo/UI 路由，且不进行真实微软授权或联网操作。
- GitHub Windows CI 同时对普通 WPF EXE、OneFile EXE 执行皮肤专项自检，并保留现有下载、登录、存档与更新回滚测试。

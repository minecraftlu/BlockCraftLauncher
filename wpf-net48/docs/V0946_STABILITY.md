# v0.9.46 稳定性维护

- 所有既有 UI、Minecraft 版本/微软登录、模组和皮肤功能保留。无新增外部依赖。
- 下载文件 SHA-1 完整性验证后再提交至目标路径；NTFS 首选 File.Replace。FAT/exFAT 等不支持该 API 时，旧文件先移至同目录的独有备份名，在新文件放置失败时恢复旧文件，成功后再清理备份。
- 设置 JSON 主文件读取失败时使用独立 LauncherConfig 尝试旧备份，防止部分解析数据污染有效备份；保持移动硬盘游戏和下载子文件夹配置。
- 发布包保持现有 GitHub Release SHA-256 / Sigstore provenance。
- 自签名证书未接入公共发布，避免误报 Windows 受信任的发布者。
- CI 验证包括便携文件替换、设置备份、完整 UI/下载/模组/皮肤、WPF+OneFile、更新回滚，以及旧稳定版到新版的真实安装替换与窗口复开。

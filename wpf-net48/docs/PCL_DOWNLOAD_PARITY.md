## 原版下载稳定性补丁：WPF Alpha 镜像回退与续传

本轮仅修改 **原 BlockCraft Launcher 的 C# WPF** 下载路径，不涉及网易房间实验，也不改变 v0.9.26 稳定版。

- 之前 CmlLib 游戏文件在官方/Mojang 与 BMCLAPI 间切换时，新建的 GET 请求会丢失原请求的 `Range`、`User-Agent` 与缓存条件等请求头。现在使用受控克隆：**HTTP Range 与公共下载头保留**，原站点回退时恢复原始请求头。
- 切换到不同主机的镜像时，**不转发 Authorization、Cookie、私有自定义头或仅针对原站点的 If-Range/ETag**。这既保留续传能力，又避免跨站点泄露令牌或使用错误的源站缓存验证。
- 镜像没有某个版本/文件而返回 `403/404/410/416` 时，自动回退到 Mojang；`429` 和 `5xx`、非用户触发的临时超时也会尝试官方。源站 `404` 仍被视为真实错误，不会无限重试。
- 游戏大文件的 HTTP 请求总超时从 45 秒提高为 **15 分钟**，仍支持安装任务主动取消；小资源下载仍有单独超时和完整性校验。
- Windows CI 新增**完全离线**的 HTTP handler 模拟测试：验证镜像失败回退、源站 404、跨域敏感头隔离、`Range`、临时超时、第三方 API 不被镜像重写，并检查 **单 EXE 打包后也能运行同样的测试**。
- 以上是组件与本机测试，不代表已在所有国内/海外运营商上完成游戏版本实测，也不表示 PCL2 的并行分块与全量修复功能已实现。

## 尚未达到 PCL2 功能等价的部分

- OptiFine/OptiFabric 自动安装、Iris/Sodium **依赖版本协调的一键组合**尚未移植；当前仅提供 Iris/Sodium 独立兼容下载与 OptiFine 官方下载页面。
- CurseForge 整合包完整安装、持久下载队列、项目版本选择及权限策略差异。
- Modrinth 完整依赖图批量自动补齐和所有类型的冲突检测。
- Minecraft 下载器自动测速选最快 CDN、每个文件的并行分块下载、真实中国大陆/海外运营商测速；目前是有上限的并行文件下载，不能承诺绝对提速。
- 暂停/恢复按钮（目前取消会保留支持 HTTP Range 的 .part 文件供下次同路径尝试续传）、关机后任务自动恢复。
- 下载速度限速器、下载诊断导出、游戏实例增量修复与完全等价的旧版配置 UI。

## 安全与兼容

不捆绑 Minecraft 受版权保护的游戏文件。安装所需资源从官方或授权服务获取。安装到游戏目录的文件需通过哈希验证；现有手动添加的同名文件不会静默覆盖。微软正版登录保留 Windows WebView2 x64 支持。

**交付状态：** WPF 下载功能预览版，建议在独立文件夹测试，不覆盖 v0.9.26 稳定版。Windows CI 编译及主窗口启动不等于游戏真实下载和安装已全面验收。

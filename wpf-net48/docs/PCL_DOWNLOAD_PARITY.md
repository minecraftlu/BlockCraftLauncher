# WPF 下载系统与 PCL2 功能体验对照（v0.9.27 下载优化）

本工程只参照 PCL2 的公开用户体验设计下载中心，**不复制 PCL2 专有源代码、UI 资源或受限服务接口**。

## 已接入本阶段

| 功能 | 当前实现 | 验证方法 |
| --- | --- | --- |
| 游戏版本浏览 | Mojang 官方版本索引、正式版/快照版/远古版分类、关键词搜索、30 分钟缓存 | Windows CI 编译 + 静态检查 |
| 原版/Forge/Fabric/Quilt/NeoForge | CmlLib 安装器，安装成功后才登记实例 | Windows CI 主窗口测试，真实联网待测 |
| 下载任务中心 | 统一列表、状态、下载字节、速度、取消、失败重试，最多 3 个不同下载任务并行 | Windows CI + 编译检查 |
| 游戏下载并发 | CmlLib ParallelGameInstaller，线程数可设 2～32 | CI 编译；多 ISP 性能待测 |
| 失败恢复 | HTTP 自动回退/限流退避/资源 SHA-1 校验/断点续传 | 代码逻辑检查；CDN 需实测 |
| 官方/镜像线路 | 官方/镜像/自动模式；BMCLAPI 仅处理已知 Mojang/Fabric 地址，并保留官方回退 | CI 编译；两地测速待测 |
| Modrinth 资源中心 | 模组、光影、资源包；版本/加载器筛选、下载量/更新排序、分页、下载校验 | CI 编译；API 需实测 |
| 整合包安装 | Modrinth mrpack 独立安装，安全路径、文件 SHA-1/SHA-512 校验、版本锁定、任务状态 | CI 编译；大型整合包待测试 |
| CurseForge 模组 | 可选 MCIM 镜像、权限边界、依赖安装、SHA-1 和不覆盖已有文件 | 默认关闭；镜像授权与实测待验证 |
| 单 EXE 分发 | 内嵌 DLL 的 x64 C# 自解压引导器，哈希检测和本地缓存 | Windows Actions 实际启动烟雾测试 |

## 尚未达到 PCL2 功能等价的部分

- OptiFine/OptiFabric、Iris/Sodium 一键组合等附加安装器；当前不提供伪造的“一键成功”按钮。
- CurseForge 整合包完整安装、持久下载队列、项目版本选择及权限策略差异。
- Modrinth 完整依赖图批量自动补齐和所有类型的冲突检测。
- Minecraft 下载器自动测速选最快 CDN、每个文件的并行分块下载、真实中国大陆/海外运营商测速；目前是有上限的并行文件下载，不能承诺绝对提速。
- 暂停/恢复按钮（目前取消会保留支持 HTTP Range 的 .part 文件供下次同路径尝试续传）、关机后任务自动恢复。
- 下载速度限速器、下载诊断导出、游戏实例增量修复与完全等价的旧版配置 UI。

## 安全与兼容

不捆绑 Minecraft 受版权保护的游戏文件。安装所需资源从官方或授权服务获取。安装到游戏目录的文件需通过哈希验证；现有手动添加的同名文件不会静默覆盖。微软正版登录保留 Windows WebView2 x64 支持。

**交付状态：** WPF 下载功能预览版，建议在独立文件夹测试，不覆盖 v0.9.26 稳定版。Windows CI 编译及主窗口启动不等于游戏真实下载和安装已全面验收。

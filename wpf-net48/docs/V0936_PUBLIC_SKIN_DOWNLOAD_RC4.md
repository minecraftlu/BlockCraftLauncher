# BlockCraft Launcher v0.9.36-wpf-rc.4 — 公开皮肤单张下载（测试版）

本版本仅在 **预览版通道** 发布；正式版 v0.9.35 和以前的 RC 不被覆盖。SignPath 证书尚未获得审批。

## 改动

- 「下载 → 社区资源 → 皮肤」继续按模组下载中心的图文、缩略图、分页、排序、作者许可证筛选呈现。
- 点击「全部公开皮肤（授权未知需确认）」可浏览 Mosaicary 公共列表中已发布、公开玩家皮肤等结果，不再只限于被标记自由许可的条目。
- **可手动下载公开 PNG，即使条目没有自由许可证或标为保留所有权。** 这不等于你获得著作权人的允许。每次对这类作品点击「下载到皮肤库」或「使用并编辑」，都会显示作者、来源和许可证状态，请用户决定是否继续。
- 默认「仅显示开放许可」筛选仍保留，且绝不把未知许可作品标注为 CC0、CC BY 或其他自由许可。
- 下载仍在「下载 → 下载任务」统一队列，提供进度、取消和手动重试；保持 HTTPS、无自动跳转、单张 4 MiB 上限、PNG 像素限制和本地临时文件安全提交。
- 下载文件保存到原有皮肤库，与 PNG 相邻的 .png.source.txt 记录作者、许可证、原始页面；对许可不明确的作品，注明下载未授予修改、再分发或商业授权。
- 「更多 → 工具 → 皮肤 DIY」仍独立，在线皮肤可在确认现有改动后进入 DIY。

## 法律、版权和网站访问

公开能访问的图片不等于开源或公有领域。应遵守作者的许可、原平台规则和所在地适用法律。对保留所有权、未知许可或存在不允许修改/商用的条目，请先联系权利人确认用途。此功能不提供绕过登录、付费、封禁、地区授权、DRM 或服务配额的下载方式，也不允许无节制批量抓取。

Mosaicary 官方 API 说明：https://mosaicary.com/developers （公开 PNG、缩略图、单 IP 每日与每分钟下载配额）。

## 测试

- GitHub Actions Windows 编译与 WPF 单文件自检、下载与皮肤安全测试必须通过，受控发布工作流独立复测以后才能创建 GitHub prerelease。
- 真实中国内地及国外不同网络、第三方站点服务可达性和 Minecraft 微软账号实际上传仍需本地实机测试；CI 离线检查不代表这些网络行为已验证。

升级：打开「设置 → 更新设置」，选择「预览版」，检查更新即可在 RC4 发布后检测它。手动下载页：https://github.com/minecraftlu/BlockCraftLauncher/releases/tag/v0.9.36-wpf-rc.4

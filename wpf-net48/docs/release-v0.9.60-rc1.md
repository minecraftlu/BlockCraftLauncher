# BlockCraft Launcher v0.9.60 RC1 · 千问 AI 助手

在首页打开「千问 AI 助手」。聊天和创作共用「连接设置」里的阿里云百炼账号配置。启用创作需要账号所在地域支持相应模型，提交请求会使用该账号的额度。

| 想做什么 | 在启动器里怎么做 |
| --- | --- |
| 连续聊天或查资料 | 在「聊天」输入问题，按 Ctrl + Enter 发送。可以接着上一轮追问，打开「联网搜索」查看模型返回的来源，或停止回答、复制、重新回答。 |
| 下次接着聊 | 打开「对话设置 → 在本机保存对话」。默认只在当前窗口保留对话。可新建、切换或删除对话。 |
| 生成图片 | 在「创作」选「文字生成图片」，例如输入“画一座雪夜里的方块小屋，有暖黄色窗光”，点「生成作品」。 |
| 修改已有图片 | 选「编辑图片」，选择本机 PNG 或 JPEG，例如输入“保留小屋，把白天改成傍晚”。生成的新图可以另存为 PNG。 |
| 生成短视频 | 选「文字生成视频」，或选「图片生成视频」并添加首帧。此版请求 5 秒、720p 视频，可以在启动器预览并另存为 MP4。 |
| 搜索或下载游戏和模组 | 继续直接说“下载 Minecraft 1.21.1”或“给当前实例装钠”。启动器使用已有的版本目录、兼容性检查和下载队列。 |

聊天中输入“把这张照片做成视频”也会打开对应的创作界面。确认描述和原图后点「生成作品」才会提交给百炼。已受理的视频任务可以停止等待，之后点「继续获取结果」取回同一任务。停止等待不会取消云端已受理的任务。

图片生成与编辑使用 Qwen Image 2.0，视频使用通义万相 Wan 2.6。文字和图片会在提交时发往所配置地域的百炼服务。公开测试使用模拟接口验证对话、图片和视频流程，未使用玩家账号发起付费生成。

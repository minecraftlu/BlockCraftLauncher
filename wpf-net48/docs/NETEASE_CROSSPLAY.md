# 网易中国版手机 + Windows 基岩互通版联机入口

这个独立 WPF 页面帮助玩家使用网易官方电脑客户端与网易中国版手机版联机，不修改 Minecraft Java 国际版实例，也不运行 Geyser 或其他协议转换器。

官方入口：https://minecraft.com.cn/

## 用户流程

1. 手机和 Windows 电脑分别安装或升级网易中国版客户端。
2. 电脑在网易官方客户端选择「基岩互通版」，而不是「Java 经典版」。
3. 手机账号 A 创建允许好友加入、支持跨端的房间；电脑使用不同账号 B 进入网易官方好友/联机大厅接受邀请。
4. 若房间不显示，检查版本、好友关系、房间权限、网络、地图或组件是否支持跨端、以及房主是否仍在线。

## WPF 集成

侧边栏「管理与工具 → 网易跨端联机」包含：

- 官方 HTTPS 网站按钮，不下载或重新分发网易官方私有安装包；
- 基于 Windows 10/11 操作系统与卸载注册表显示的启发式安装检测；
- 用户自主选择已安装的官方 EXE 并保存路径，在 Windows Shell 中打开；
- 创建和加入房间的步骤、联机注意事项及可复制的排查清单；
- 不访问网易账号、Token、房间列表或私有协议。

已安装软件检测只用于提示。无法自动辨别每个游戏版本或全部软件路径。任何误匹配不自动运行。
正式的游戏登录、版本更新与好友进房操作仍由网易官方客户端执行。

CI:
- Python 静态检查：tests/check_netease_crossplay.py
- WPF 与 single EXE：--netease-ui-selftest（不打开网站、不启动外部程序、不读取账号和服务器）

Windows CI 能验证界面启动和相关 API，但不能替代两台真实设备的网易跨端联机验收。

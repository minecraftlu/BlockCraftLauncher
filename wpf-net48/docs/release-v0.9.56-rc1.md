# BlockCraft Launcher v0.9.56 RC1 测试版

Windows 用户可下载 `BlockCraftLauncher-v0.9.56-WPF-OneFile-Windows-x64.exe` 直接运行。已使用测试更新通道的用户也可以通过启动器更新。

* 在「下载 → 游戏内容 → CurseForge 官方」按游戏版本和加载器筛选模组，选择作者发布的具体文件及目标实例。安装任务会处理必需前置，并校验 JAR 的大小和 SHA‑1。
* 同一页可单独下载 CurseForge 官方 Windows 客户端安装包。启动器验证 Overwolf 发布者的 Windows 数字签名后保存安装包，玩家可以自行决定何时运行。
* 普通玩家可以自动读取项目方发布的公共服务地址。发布此版本时，公共模组服务仍待维护者配置新密钥并完成联网验证，页面会显示实际配置状态。已配置有效本机密钥的维护者可以直接访问官方 API。
* 启用公共服务后无需重新下载此版本。作者关闭第三方分发的模组可以从项目官方页面查看。

# BlockCraft Launcher v0.9.36-wpf-rc.3 · 独立皮肤下载中心

仅 GitHub 预览版。v0.9.35 正式版保持不变，SignPath Foundation 数字签名仍在审核。

## 分类和布局

- 顶部 **下载 → 社区资源 → 皮肤**：与模组、整合包、资源包和光影包并列，使用相似的搜索、筛选、带图结果卡片与详情预览。
- 顶部 **更多 → 工具 → 皮肤 DIY**：只保留离线绘画、PNG 导入导出、皮肤库、恢复草稿和正版微软账号确认上传。
- 两页可以互相跳转；保持同一编辑器对象与草稿。选中在线皮肤后按「使用并编辑」可进入 DIY，舍弃未保存修改需显式确认。

## 公开图库覆盖范围

- **Mosaicary**：使用官方公开只读 API 搜索已发布的标准皮肤。每页 24 项，可按分类、模型、下载量、人气、关键词筛选并持续翻页浏览源站所有允许公开索引的页面。
- **DP-Plugins**：其公开目录最多一次列出 200 件，支持关键词及作者名称搜索；可以与 Mosaicary 合并浏览。访问速率由原网站决定。
- **Minecraft/Mojang 玩家皮肤**：可按具体 Java 用户名或 UUID 查看玩家当前皮肤。这些皮肤通常没有开放再分发许可，绝不能等同于 CC0 或其他开源作品。
- **Mosaicary 已公开玩家皮肤**：可选择「全部公开皮肤（未授权仅预览）」浏览站点公开索引的玩家贴图，默认不当作自由授权作品；这类皮肤只展示原站信息和预览，不开放保存/使用操作。不会尝试获取非公开、已撤回或受限贴图。
- 公开可访问不等于自由许可；默认仅列出明确 CC0、CC BY、CC BY-SA 等允许使用的图库条目。未授权/受限条目可查来源，但不能被冒充为开放素材。

## 下载管理升级

- 「下载到皮肤库」接入主启动器 DownloadTaskCenter 队列，可以从 **下载 → 下载任务** 查看任务、取消失败任务或主动重试，和模组任务一同管理。
- PNG 下载限制 HTTPS、不允许自动重定向、最大 4 MiB、尺寸仅 64×64 或旧 64×32。文件经重编码、唯一名称、临时 staging 和无覆盖提交，避免损坏已有皮肤。
- 保存到现有的 %APPDATA%/BlockCraftLauncher/Skins，生成同名 .png.source.txt 保存作者、许可和来源链接。遵守 CC BY 署名、CC BY-SA 相同方式共享及网站限流规则。
- 下载服务发生错误时不阻止离线 DIY。只有用户主动搜索才发起外部请求，不会后台批量抓取、绕过配额或授权。

## 发行与测试

发布前由 Windows CI 自动运行 WPF / OneFile 编译、皮肤和下载自检、UI 导航与窗口测试、更新器回滚、哈希生成。必须确认受控 GitHub prerelease 的测试全通过后才发布。

外部源站在中国内地和海外的真实连通性仍需玩家测试。不能声称收集了全互联网皮肤、完美兼容所有地区或已通过数字证书审核。

升级方式：在已有启动器的「设置 → 更新设置」选择「预览版」，再检查更新。RC3 发布后页面为 https://github.com/minecraftlu/BlockCraftLauncher/releases/tag/v0.9.36-wpf-rc.3 。

详情请参见 ONLINE_SKIN_SEARCH.md 与 PRIVACY.md。

# BlockCraft Launcher v0.9.58 RC1 · 千问 AI 搜索

直接下载并运行 `BlockCraftLauncher-v0.9.58-WPF-OneFile-Windows-x64.exe`。已经使用预览通道的玩家可以在启动器内检查更新。

在首页或「更多」打开「千问 AI 搜索」。输入 Minecraft 问题，点「搜索」或按 Ctrl + Enter，回答会出现在当前页面。服务返回来源链接时，可以点击查看原文。搜索可以取消，也可以复制回答。

首次使用时展开「连接设置」。默认模型是 `qwen4-max`。如果本机已配置潮汐桌伴，点「使用桌面伙伴配置」即可带入桌伴使用的百炼接口和千问模型。也可以手动填写北京或新加坡地域的百炼接口及支持联网搜索的模型。

在启动器中填写自己的百炼 API Key，或使用本机环境变量 `DASHSCOPE_API_KEY`。只有勾选记住密钥并保存，启动器才会用当前 Windows 账户加密保存手动输入的密钥。桌伴的密钥、聊天记录和游戏账户均不会随模型配置导入。每次主动提交问题都会向百炼发起模型与联网搜索请求，费用按所用百炼账户的规则结算。

模组、整合包、光影和资源包的搜索与安装仍在「下载」。千问回答中的网页链接需点击后才会在默认浏览器打开。

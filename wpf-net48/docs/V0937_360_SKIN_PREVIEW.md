# v0.9.37 皮肤 360° 鼠标预览（测试版功能）

## 操作方式

- 「更多 → 工具 → 皮肤 DIY」页面：右侧人物预览新增可鼠标操作的 3D 模型，保留正面和背面 2D 对照。编辑贴图、撤销、导入本地 PNG、切换 Steve/Alex 手臂类型、显示/隐藏外层时同步更新 3D 外观。
- 「下载 → 社区资源 → 皮肤」页面：选择皮肤并完成 PNG 预览后，在详情卡片显示相同的 3D 模型；页面不主动上传 PNG。
- **按住鼠标左键左右拖动**：水平连续旋转人物，可完整查看背面；上下拖动：调整俯仰角，限制在 ±55°。
- **滚轮**：缩小或放大。**重置视角**：回到默认斜前方角度及缩放。
- 支持 Java 64×64 皮肤，Steve 宽臂、Alex 细臂，头部帽子、上衣、袖子、裤腿外层。旧版 64×32 PNG 由原有导入器标准化后显示。

## 技术和安全

- 使用 **.NET Framework 4.8 自带 WPF Viewport3D / MeshGeometry3D**，不引入网页 3D SDK、CDN 或额外 NuGet 包。
- 读取皮肤编辑器生成的本地 64×64 贴图，通过 Minecraft Java 皮肤 UV 展开区域映射到头、身体、左右手臂、左右腿各六个面；外层使用稍大的盒体避免穿插闪烁。
- 仅预览当前皮肤，不自动上传 Microsoft 账号；在线皮肤仍须遵循原有来源、授权和下载确认。
- 在线图册未选中皮肤、图片异常时保持空白预览，不显示伪造的 3D 形象。

## 验证

- Skin3DPreview.VerifyGeometry()：Steve、Alex 基础层和外层 12 组立方体的网格数量、UV 范围。
- UI 离线布局回归：校验渲染模型数量、水平旋转、俯仰角限制、滚轮缩放范围和重置视角。
- GitHub Actions 的 Windows WPF 编译、窗口、DIY 自检通过后，才可供用户下载测试构建；**CI 不能替代真实 Windows 机器上的鼠标交互和不同显卡实测**。
- 保持 v0.9.36 稳定版不变。是否升级为稳定版应以用户实测成功为前提。

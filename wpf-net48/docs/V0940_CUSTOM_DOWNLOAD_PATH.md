# v0.9.40 预览版候选：自定义下载位置

## 设置入口
- **设置 → 启动设置 → 游戏根目录 → 选择文件夹**：后续 Minecraft 正版/加载器安装的默认位置。已安装实例的目录不会自动迁移，模组与资源包仍安装到当前实例下。
- **设置 → 下载设置 → 下载缓存目录 → 选择文件夹**：控制启动器更新包、SHA-256 清单、解包临时文件和 Modrinth 整合包的临时下载位置，例如 `D:\\BlockCraftDownloads`。可使用其他固定磁盘，不强迫占用 C 盘。
- 每次保存设置时检查必须为本机绝对路径、不能指向磁盘根目录/Windows/用户主目录/Minecraft 游戏及存档目录、不能经过链接目录、必须可创建并写入测试文件。拒绝失败的更改，不修改用户游戏资料。

## 更新与兼容性
- 更新准备阶段写入 `<下载目录>\updates\staged-<GUID>`，并标记为启动器创建的专用暂存文件夹，随后下载、校验 SHA-256 和执行自检。
- 独立更新助手接收经过检验的暂存目录位置，仍然 **替换旧 EXE 原路径**，不从下载目录直接启动旧版，也不会改变桌面快捷方式。
- 新版窗口显示成功后，独立助手只删除本次匹配的暂存文件夹；失败时保留旧 EXE/回滚资料。
- 启动器可以清理先前旧版的 `%LOCALAPPDATA%\BlockCraftLauncher\updates` 缓存，也会清理自定义目录中标记匹配且超过 48 小时的旧暂存文件夹。不会删除用户自定义目录本身、普通 EXE、Minecraft、皮肤库或任意用户文件。
- 原有设置缺少 `download_directory` 时继续使用过去的 LocalAppData 缓存路径；改变设置不会移动旧缓存、下载中的任务或已有 Minecraft 实例。
- 自定义盘断开或无写入权限时，明确报告错误而非自动改用系统盘，也不会破坏原启动器。

## 测试验收
1. 路径验证：本机绝对路径通过；磁盘根目录、系统目录、相对路径、Minecraft 内部、UNC 均拒绝。
2. 设置持久化：保存 `download_directory` 后读回一致；旧配置仍能读取。
3. UI：游戏根目录和下载缓存目录均能通过 Windows 文件夹选择器选取；非法目录保存被阻止。
4. 升级：ZIP/OneFile 原位更新，下载目录自定义时新旧版本确认后清除已标记暂存目录，但保护邻近用户文件；测试失败可回滚。
5. Windows CI：下载、模组、皮肤、UI、自更新以及 SHA-256/Sigstore 来源证明检查。

正式版 v0.9.38 不受影响。首次在 RC 测试版验证后才考虑稳定版发布。

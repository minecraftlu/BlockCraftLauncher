# BlockCraft Launcher v0.9.62 RC1 · 本地千问

从「千问 AI 助手 → 本地 AI」选择用途。首次使用时，展开「模型存储位置」选一个空间充足的文件夹，点「准备模型」即可在启动器里下载安装。模型独立于启动器 EXE，更新启动器后可以继续使用。也可以选择移动硬盘，使用时接回同一位置即可。

| 用途 | 本机模型 | 首次下载 |
| --- | --- | --- |
| 聊天与下载指令 | Qwen3.5-4B，通过 Ollama 运行 | 模型约 3.4 GB。需要安装 Ollama 时另下载约 1.7 GB |
| 生成图片 | Qwen-Image-2512，FP8 | 从零安装约 32.0 GB，包含图像运行环境和共享组件 |
| 修改图片 | Qwen-Image-Edit-2511，FP8 | 从零安装约 32.1 GB。已经装好画图模型时，新增约 20.5 GB |

两个图像模型都装在同一目录时合计下载约 52.6 GB，运行环境解压和生成的图片还需要额外磁盘空间。本版的本地图像功能面向支持 CUDA 12.6 的 NVIDIA 显卡和 Windows x64。推理速度和可用分辨率受到显存及系统内存影响。

- **聊天和搜索**。输入「帮我找一个提升帧率的模组」，本地千问会给出搜索词，启动器随后打开模组目录。确认项目、版本和实例后可以安装。明确指定游戏或模组的下载指令继续使用启动器的下载队列。
- **画图**。选择「生成图片」，输入画面描述，生成后即可预览并保存 PNG。
- **改图**。选择「修改图片」，选一张自己的截图，输入「把村庄里的白天改成黄昏」，生成后另存结果。

本地对话和图像推理使用自己的电脑，无需千问账号、API Key 或百炼额度。首次安装模型、搜索在线模组和下载游戏文件需要联网。千问官网账号登录和原有的百炼创作仍可在各自的标签页使用。

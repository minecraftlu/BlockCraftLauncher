# v0.9.37 计划：扩大开源 Minecraft Java 模组搜索与下载范围

**状态：开发分支功能，尚不是已经发布的稳定版。**
当前正式版仍以 GitHub Releases 的版本为准，不能把本文件描述成“所有模组 100% 兼容”。

## 开源模组来源与功能

1. **Modrinth**（主来源）
   - 搜索和下载支持的 Minecraft Java 模组、光影、资源包、整合包。
   - 按当前实例的 Minecraft 版本和加载器查询服务端兼容版本，避免过长未过滤的版本清单。
   - 自动查找并安装 Modrinth 已声明的必需依赖，保持安装事务、冲突防护与 SHA-1 文件校验。
   - 优先选择经过校验的可运行 JAR，忽略源代码 JAR、开发包及 Javadoc JAR。
2. **CurseForge**（需用户明确启用 MCIM 镜像）
   - 沿用已有的 CurseForge 模组搜索、详情图标、兼容性检查与必要依赖下载。
   - 仅使用获得有效文件哈希和受支持 HTTPS 地址的项目。
   - 不借用私人 API Key，也不绕过项目作者的限制。
3. **GitHub 开源仓库 / Releases**（下一版新增）
   - 从 GitHub 官方公开仓库搜索 Minecraft 模组，**只显示可识别 SPDX 开源许可证**的项目。
   - 安装时再次确认仓库仍公开、未归档且仍有开源许可证。
   - 只考虑当前 Minecraft 版本、对应加载器、官方 Release 下载地址以及 GitHub API SHA-256 摘要都匹配的 JAR。
   - 下载后检查 SHA-256、完整的 JAR 容器以及 Fabric / Forge / NeoForge / Quilt 模组声明，成功后才移动到实例的 mods 文件夹。
   - 不覆盖用户已有 JAR，不下载源码 ZIP、安装器、未核验的模组或未知第三方 CDN。
   - 无法唯一确定要安装的 JAR、版本或加载器时**拒绝自动安装**，建议查看项目原始说明。
   - GitHub 项目的依赖有可能不在 Modrinth，当前不会猜测或自动解决这些依赖。项目作者可能要求手动安装其它组件。
   - GitHub 匿名搜索存在 API 速率限制，仓库即使开源也可能**没有**构建好的 JAR、没有 Releases、没有可供下载的兼容版本。

**重要区别：** GitHub 上公开的源码并不自动等于开源许可；公开的开源仓库也不必然提供可安装的模组文件。
本功能不声称覆盖所有作者、所有加载器或所有游戏版本，不绕过下载服务规则，也不保证资源在中国大陆或海外都可访问。

## 兼容和安全边界

- 当前自动安装仅面向 **Minecraft Java Edition**，不兼容网易版移动端／基岩版插件。
- GitHub Releases 的 SHA-256 来源由 GitHub 平台提供，有助于检测下载文件与 GitHub 上传资产不一致。
  该摘要并不等于作者另外发布的独立签名，也不保证 JAR 不含恶意逻辑。
- 根据仓库元数据识别许可证只是第一道筛选，项目作者的源码和二进制发布许可仍应由用户确认。
- 不把 GitHub Release 资源登记为 Modrinth 托管模组，避免错误地使用 Modrinth 更新接口覆盖文件。
- GitHub 项目没有严格标准化的 Minecraft 版本和依赖元数据，本次采用保守的文件名 / Release 版本提示和 JAR 内容核查，**不进行自动编译和任意脚本执行**。
- 下载仅在用户选择并确认后发生。任何模组都是第三方程序，请只安装可信作者的项目。

## 测试与发布要求

GitHub Windows CI 需要至少通过：
- 原有 WPF / OneFile 双发行版编译与启动自检；
- Modrinth 依赖拓扑、版本筛选、源码 JAR 排除及哈希规则；
- GitHub 搜索公开许可证筛选、下载来源 URL、SHA-256 摘要、版本/加载器选择、假 JAR 排除；
- 网络下载回退、微软正版登录恢复、单文件启动器和更新器回滚测试；
- 免费 Sigstore 签名和 GitHub 构建证明。

CI 离线模拟不等于已完成真实设备上 Modrinth / GitHub / CurseForge 的逐模组下载兼容性验收。
正式发布仍使用人工验收的受控发布机制；不会仅凭 CI 通过就自动把 v0.9.37 推送为正式版。

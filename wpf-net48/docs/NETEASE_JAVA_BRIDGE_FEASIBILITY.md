# BlockCraft Launcher：Java 客户端直连网易手机版联机环境（可行性与实施边界）

> 状态：研究阶段 / 尚未实现。**不要求安装网易 Windows 客户端**。

## 用户明确要求

- 用户使用 BlockCraft Launcher 启动国际 Minecraft Java 客户端。
- 网易手机版玩家继续使用手机网易中国版，联机目标是**网易已有的手机联机大厅房间或官方网络游戏**。
- 两端玩家处于**同一个网易服务器或房间**；不能用重新搭建 Paper+Geyser 的新世界替代。
- 不捆绑或启动网易官方电脑客户端，不允许用“跳转官网下载”来充当互通成功。

## 当前技术判断

1. Geyser 原生方向为 Bedrock 客户端 -> Java 服务器，不能用于让 Java 客户端加入网易现有手机房间。
2. ViaProxy / ViaBedrock_NetEase 是协议翻译的潜在技术路线。社区文档明确要求配置目标服务器 `target-address: host:port`，只可作为**已知且获准连接地址**的实验性桥接候选。
3. 网易手机联机大厅涉及平台的房间发现/加入、账号授权、网络中继或端到端协商。没有找到经过验证、可供国际 Java 客户端合法调用的公开房间加入 API。房间号码通常不能直接当作 Minecraft IP 使用。
4. 网易官方网络游戏还可能使用分平台服务器列表、独立验证和反作弊，协议转换成功不代表获得进服许可或能正常游戏。
5. 因为缺少 3/4 的实测接口，**目前不能承诺支持直接输入网易大厅房间号或加入任意官方小游戏**。

## 可实施的分期

### A：仅限获准连接、具有明确地址的服务器
- 给 WPF 启动器新增实验性的 NetEase Bridge 服务，按用户选择自动启动经过审查的 ViaProxy/ViaBedrock_NetEase 实现。
- 不需要网易电脑端；仍由原 Java Minecraft 实例连接本地回环代理。
- 检查游戏/协议版本，建立 TCP 本地监听与 UDP 远端会话，反馈握手/超时/拒绝的精确诊断。
- 用户明确配置服务器地址，且服务端确实接受协议与身份；不能推广成手机大厅/官方小游戏支持。
- 第三方组件需要版本固定、许可核对、SHA-256、明确告知和用户同意；不把第三方软件以错误名义打包为“全功能可用”。

### B：网易联机大厅房间
- 先确认有权使用的账号认证、房间列表/邀请发现、房间路由及授权接口；以合法公开/获准的集成机制完成。
- 无可用接口或相关服务器拒绝时，功能保持禁用并说明原因；不伪造在线房间或承诺随意加入。
- 联合用户自有/授权房间进行真实双端验证，确认房间加入、聊天、区块、动作和离线重进。

### C：网易官方网络游戏
- 在服务方允许的前提下，分别验证服务器握手、账号与资源要求，不能假定所有游戏通用。
- 不自动窃取账号、绕过反作弊、假冒官方客户端或从未知来源下载其游戏资源。

## 可验证成果的最低标准

- 使用 BlockCraft Launcher 的国际 Java 客户端成功连接指定目标；
- 手机网易玩家仍位于同一房间，能互相看到、移动、聊天，传送/存档行为一致；
- 断开与重新连接正确，无账号泄露；日志不包含密码、Token、Cookie；
- 由真实用户电脑验证，不能以 Windows CI 编译通过代替联机通过。

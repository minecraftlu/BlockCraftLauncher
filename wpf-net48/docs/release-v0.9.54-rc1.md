适用于 Windows 10/11 x64（.NET Framework 4.8）。只需下载单文件 EXE 即可运行。

- **桌面文件名跟随版本。** 本版的单文件名为 `BlockCraftLauncher-v0.9.54-WPF-OneFile-Windows-x64.exe`。以后升级时，文件名会使用实际下载的新版本号。
- **校验完成后直接出现在桌面。** 单文件启动器在所选更新通道发现新版后，会按「自动下载」设置下载并校验。即使推迟安装或关闭自动重启，仍可在桌面找到已校验的新版 EXE。
- 新版成功打开后才清理本次更新的旧 EXE。桌面已有其他同名文件时会保留原文件并为新版加序号。已有相同完整文件时直接复用。
- 从公开的 v0.9.53 RC1 单文件版更新到本版时，也会把旧更新器生成的桌面文件改为带版本号的名称。

现有用户可在「设置 → 更新设置」通道中选择「预览版」并检查更新。单文件版与完整 ZIP 分别附有 SHA-256 校验和和 Sigstore 签名。

# v0.9.37 RC4 候选：皮肤 3D 预览渲染修复

## 现象与原因

RC3 预览可能显示帽子轮廓、上衣图案和裤腿等破碎、悬浮的片段，看不到完整皮肤模型。根因是 WPF 3D 使用透明纹理构建完整外层立方体时，完全透明的外层纹素仍可能写入深度缓冲区，使身上的基础层几何被不透明地遮挡。

## 处理

- 不再为外层六个面构建整块带透明像素的三角面：逐像素检查本地 64×64 PNG，**仅为 alpha > 0 的外层纹素创建小面片**。原本完全透明的区域不再产生遮挡基础层的几何。
- 基础层仍以六面立方体显示；渲染外层和基础层之间保留安全距离，帽子外层扩大约 0.75 单位，衣袖等外层扩大约 0.55 单位。
- 外层片段使用对应纹素中心采样，避免 atlas 邻接透明像素的边缘混色；保留 Steve 宽臂、Alex 细臂。
- 优化相机角度、光照、微弱背景渐变；DIY 与在线皮肤详情扩大 3D 展示区域。
- 左键拖动旋转，滚轮缩放，双击/按钮重置。增加可暂停的自动旋转按钮；离开页面自动停止，避免后台消耗。
- 皮肤详情可切换显示/隐藏外层，不影响皮肤文件本身。与现有 PNG 下载和微软上传权限保持隔离。

## 自检

Windows WPF --ui-layout-selftest 在标准与单文件 EXE 中验证：
- Steve 和 Alex：无像素的外层不会生成任何三角面，单个不透明外层像素正好生成一片面；
- 关闭外层后仅保留六个基础部件，重新开启可恢复；
- 手动旋转、俯仰角上限、滚轮缩放范围、重置视角、自动旋转开关；
- 皮肤绘制、撤销和实时同步保留原行为。

仅在 Windows CI 通过后发布为独立 RC4 预览包。CI 不能代替真实 Windows 用户在不同显卡上检查旋转流畅度、透明像素与 UI 大小。稳定版 v0.9.36 不受影响。

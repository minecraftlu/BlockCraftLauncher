# BlockCraft Launcher · 直接打开新版（v0.9.30 RC2 候选）

日期：2026-11-10。此功能为用户要求的正式版目标功能，但**尚未完成实机验收，因此先在 RC2 候选版验证**。

## 两种更新操作

| 功能 | 行为 | 安装位置 |
|---|---|---|
| 下载并安装 · 完成后自动打开新版 | SHA-256 验证；明确确认；旧 WPF 退出；独立更新助手覆盖原 EXE 或 ZIP 应用文件；自检后自动打开新版主窗口；失败回滚 | 更新**现有安装路径** |
| **直接打开新版（不覆盖旧版）** | 发现新版 → 下载并校验 → 用户明确确认 → 从受信任暂存目录直接打开新版 → 等待新版主窗口真正渲染后再关闭旧版窗口 | **只是临时试用；旧版安装路径不变** |

「直接打开」后，再次从原来的桌面快捷方式启动，仍会启动原版本。需要永久升级时请用「下载并安装」。

## 技术与安全

- 可用性：自动检查得到同一 GitHub 官方 Release 的 WPF 兼容更新包，只有用户选择「直接打开」才启动。没有新版本时按钮禁用。
- 使用已经经过完整 SHA-256 校验的 EXE/ZIP；打开前再次验证预期文件哈希。对于 ZIP，除内部 SHA-256 清单外，逐一比对所有解压后的文件与已核验 ZIP 中的原始条目，拒绝新增、遗漏或篡改的 EXE、DLL、其他文件。
- 所有可执行文件必须位于 `%LOCALAPPDATA%\BlockCraftLauncher\updates\staged-<随机 GUID>`，不接受任意用户指定本地路径。
- 直接打开时传入一次性 `--after-update <token> --direct-open`，新版 WPF 的 `ContentRendered` 事件写入真实窗口进程 ID；得到有效确认后才关闭旧版窗口，避免关闭后无法打开新窗口。
- 这不是复制 PCL2 的源码或界面资源，是 BlockCraft 自有实现；游戏/存档/账号目录不参与此操作。

## 测试

- 普通 WPF 和单 EXE Windows UI 回归执行两套启动模式（自动安装后重启 / 直接打开临时预览），验证真实渲染的主窗口 PID 与确认令牌。
- 离线回归测试校验单 EXE 损坏拒绝、伪装路径拒绝、解压后的 ZIP 有额外文件、EXE 被篡改以及原 ZIP 被篡改时拒绝直接打开。
- 待真实设备验收：GitHub 在线下载、直接打开新版本后实际显示 UI、旧版只在新窗口显示后关闭，以及是否按预期保留原快捷方式安装。

**Stable 门槛：** v0.9.30 RC2 发布并通过 Windows CI 后，还必须有用户实际 Windows 端验证两种更新方式，才能合并到正式版。不能仅凭 CI 声称已有正式稳定版。

# BlockCraft Launcher v0.9.61 RC1 · 窗口内使用千问官网

从首页打开「千问 AI 助手」，即可在启动器窗口中使用千问官方网页版。点网页内的「登录」，按千问提供的方式登录自己的账号。使用官网无需填写百炼 API Key，网页功能与用量以千问账号页面为准。

| 入口 | 用途 |
| --- | --- |
| 千问官网 | 使用官方聊天界面，查看网站域名、后退、刷新或返回官网首页。网页登录状态保存在当前 Windows 用户的浏览器数据目录，启动器更新后可继续使用。登录过期时按官网提示重新登录。 |
| 聊天与指令 | 向启动器发送“下载 Minecraft 1.21.1”“给当前实例装钠”等指令，或使用此前配置的百炼对话。 |
| 百炼创作 | 继续使用自己的百炼连接生成图片、编辑图片和生成视频。 |

网页版使用 Microsoft Edge WebView2 Runtime。若系统缺少运行时，点页面上的「获取 WebView2 运行时」，安装后回到启动器点「重试」即可。

测试版支持从 v0.9.60 RC1 检查更新，也可直接下载 Windows 单文件 EXE。网页登录和退出由千问官网处理。

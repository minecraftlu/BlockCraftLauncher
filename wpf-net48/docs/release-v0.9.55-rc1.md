适用于 Windows 10/11 x64（.NET Framework 4.8）。本次重做 BlockCraft 的启动器界面和加载画面。布局参考 PCL2 的分类导航和 HMCL 的实例操作，图标、插画和界面实现沿用或新制于 BlockCraft。

- **启动与实例。** 首页聚焦已选实例、账号和启动操作，版本管理支持从实例进入设置、已安装内容与存档。启动游戏时显示实际执行阶段。
- **下载与管理。** 模组页集中搜索、下载源和目标实例，把版本、加载器、分类及排序放入可展开的筛选区。任务管理和资源详情随选中项更新，原有安装、依赖、队列和重试流程可继续使用。
- **联机、皮肤与设置。** 联机独立显示在顶栏，服务器收藏、在线查找和局域网各有入口。皮肤库、DIY 编辑和 3D 预览使用统一的布局。微软登录、离线登录和更新设置仍可通过相应入口使用。
- **启动画面。** 单文件解包、准备界面和主窗口首次绘制之间使用统一的加载画面。浅色、深色和 Windows 高对比度均有对应显示。
- **更新。** 保留 v0.9.54 的桌面自动下载、版本文件名和确认新版可用后清理旧 EXE 的行为。已有用户可以在「设置 → 更新设置」选择「预览版」检查更新。

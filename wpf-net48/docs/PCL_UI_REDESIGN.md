# BlockCraft Launcher v0.9.27 WPF · PCL2 风格界面重排

> 这是在原 BlockCraft Launcher 基础上借鉴 PCL2 **布局层级与交互组织** 的独立 WPF 设计；不包含 PCL2 原始图标、源代码或品牌素材，也不宣称完全复刻其功能。

## 解决的实际截图问题

用户在 Modrinth 资源中心的实机截图中反馈：英文项目名称和长描述拼成单行、滚动条叠加、左侧全部为大按钮、搜索与排序分散、没有清楚的标题/详情/下载操作层级。

本轮改动：

1. **统一应用主题**：`App.xaml` 添加两套动态明暗色彩 token，蓝色强调色、柔和背景、白色/深色独立卡片、统一圆角/边框/间距/控件高度。主题与自定义强调色继续通过原设置入口即时更新。
2. **窗口骨架**：`MainWindow.xaml` 调整为 66px 顶部主导航 `启动 / 下载 / 设置 / 更多` + 205px 上下文侧边栏 + 独立页面滚动 + 36px 固定状态栏。取消正常比例下多余的外层滚动，仍允许 80%-140% 缩放时滚动视口；首页保留宽屏单栏布局。
3. **侧边栏**：游戏、资源下载、管理与工具分组；添加各项独立图标符号、静态颜色反馈、统一选中样式。首页隐藏侧边栏，其他页面保持可操作。
4. **首页**：当前游戏实例、醒目启动按钮、账号管理、快捷下载/资源/设置入口、预览提示分块；不再有占用大量空间的四个巨型导航按钮。
5. **Modrinth/光影/资源包**：顶部搜索卡片与可换行的过滤器；结果列表按 **项目标题、完整换行描述、中文分类** 三层显示。列表内容独立滚动，不再由 `ToString() = Name + " — " + Description` 导致单行长文本横向截断。双击项目可调用已有资源安装流程；原有安装/下载任务/实例目录按钮继续有效。回车可直接搜索。
6. **整合包、CurseForge、游戏版本、下载任务**：统一资源/版本/下载状态 DataTemplate，不再只显示长条一行；Modrinth 项目类别中文化而不改变真实项目 ID、兼容筛选/下载/校验逻辑。
7. **可伸缩工具栏**：共享 `Row` 使用 `WrapPanel` 代替固定 `StackPanel`，使较窄窗口下的排序、筛选、按钮能够自然换行。
8. **原下载功能保留**：Mojang/BMCLAPI 镜像回退、Range 续传、Modrinth/CurseForge/整合包及 SHA 校验仍由现有服务负责；未引入外部 UI 库或账号隐私数据处理改变。

## 验证

- 继续使用原 `build-windows.bat`，输出 .NET Framework 4.8 Windows x64 一般 ZIP 及现有独立 OneFile EXE。
- 新增 `--ui-layout-selftest`：创建同一个 WPF 主窗口，并离线验证顶部导航、首页切换、游戏版本行模板、Modrinth 长中文描述布局、光影/资源包/整合包导航、下载任务绑定和设置页面。退出码为 0 才算通过。
- GitHub Actions 新增正常程序与 OneFile 两组布局 smoke test，并保留下载镜像回退、微软登录恢复与启动依赖等全部历史测试。
- 仍须由用户在实际 Windows 电脑确认字体、窗口 DPI 和触屏/小屏体验；CI 不能替代视觉验收。
- 正版 Microsoft 凭据、游戏账号和 Minecraft 下载不会参与 UI 自测。

## 后续视觉验收清单

1. 100% / 125% Windows DPI，常见 1366×768 / 1920×1080 窗口下顶部导航是否无遮挡。
2. Modrinth 20 条资源的长英文描述是否完整换行，并且滚动时不出现水平滚动。
3. 下载页剩余任务和选中状态、进度条、百分比不会绑定异常。
4. 暗色模式下列表选中态、占位文字与按钮对比度充足。
5. 各页面均可返回顶部导航并通过左侧子页面进入现有安装流程。

**目前属于 PCL2 风格的信息架构与文字排版改进，不应夸称已完整复制 PCL2 的所有交互/全部功能。**

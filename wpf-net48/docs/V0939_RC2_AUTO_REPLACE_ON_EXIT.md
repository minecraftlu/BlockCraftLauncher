# v0.9.39 RC2 方案：退出启动器时自动原位替换已校验的新版本

## 目标
新版下载完成后不再需要反复下载、手动另存 EXE、清理多个旧程序。
原有“更新并替换旧版”仍可立即执行。新增 **设置 → 更新设置 → 自动安装**（默认关闭），开启后同时开启启动检查和自动下载。

## 生效时机
只有用户正常关闭当前启动器、存在 SHA-256 验证和 smoke-test 通过的候选包、更新候选没有变化、当前不在下载或检查中，而且未进入临时试用流程时，才会启动独立更新助手。助手等待旧版进程退出，原位置替换目标 EXE / ZIP 安装目录，在新版窗口确认显示后才清理自有旧备份与更新缓存。

## 不做的事情
- 不在游戏或窗口正常使用过程中强行中断启动器；不在下载时抢先覆盖文件。
- 不在首次启动时未经许可修改 EXE；默认只是提示或下载更新。开关为持久化明确授权。
- 不删除用户 Downloads 桌面自行保存的历史 EXE，也不遍历 Minecraft 世界、模组、账号或外部磁盘。
- 如果外部更新助手启动失败，原 EXE 继续保留并记录错误；不强制拦截用户正常关闭窗口。
- 临时试用新版（不安装）和手动安装已启动的场景都绕过退出自动安装，防止重复启动两个更新助手。

## 测试
1. SettingsStore 保存和读取 `auto_install_updates_on_exit`，已有旧设置不包含此字段时默认关闭。
2. 下载自检：授权且候选一致才允许退出自动安装；未授权、未自动检查下载、后台忙、临时试用、候选更新后全部拒绝。
3. UI 自检：显示自动安装开关和说明，默认不打断当前使用。
4. Windows CI：.NET Framework 4.8 WPF / OneFile、ZIP、更新器回滚、窗口重开、Sigstore / GitHub 来源证明。
5. RC2 独立预览后，从 RC1 升级到 RC2 进行真实同路径覆盖与清理验证，再考虑正式版。

建议用户先在测试版验证“自动安装”选项；当前稳定版 v0.9.38 不做自动行为变更。

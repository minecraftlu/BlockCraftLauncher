# v0.9.44 正式版候选：PCL2 风格统一与自动更新切换

## 本分支已实现的行为

- 新安装默认启用“检查更新 / 自动下载 / 下载校验后自动切换”，原有用户在设置中明确关闭的选项继续生效。
- 下载和 SHA-256 校验通过后，若无游戏进程、下载任务、账号操作、未保存的皮肤编辑或正在使用的输入框，约 2 秒后自动交给独立更新助手。
- **先关闭旧版窗口**。旧进程退出后，独立更新助手在原安装位置替换单文件 EXE 或 ZIP 内容，执行新版启动自检，再打开新的主窗口。
- 替换失败时保留原有文件回滚；只有恢复后的原启动器 EXE 与更新前 SHA-256 完全一致，才尝试重新启动旧版。不会扫描、删除或迁移 Minecraft 存档与模组。
- 用户仍可在短暂倒计时中“稍后更新”，忙碌时不会中断游戏或下载。
- 调整通用导航侧栏宽度、菜单行高、卡片圆角/边距、过滤控件和更新设置文本，沿用 PCL2 式分区逻辑与 BlockCraft 自有图标素材。

## 目前**不能**宣称的内容

- 尚未在用户实际 Windows 环境完成所有屏幕尺寸、DPI、Microsoft 登录和国内/国外真实网络下载的端到端验收。
- 统一借鉴 PCL2 的布局与信息组织，并非完全复制 PCL2 的所有 UI/功能/品牌素材。
- 尚未打正式版 v0.9.44 标签，不应向稳定通道推送未经过完整 Windows CI 与实机验收的二进制。

## 发布前必须通过

1. Windows GitHub Actions 全套静态检查、WPF/OneFile 构建、更新文件回滚、窗口就绪与 UI 布局检查。
2. 旧版 v0.9.42 稳定版升级到候选版的两种发行形式（单 EXE / ZIP），检查旧窗口先关闭、新窗口打开、原文件名保留和备份清理。
3. 失败场景：离线、更新包损坏、目标 EXE 被安全软件锁定、移动硬盘中途拔出、运行中的 Minecraft、未保存的皮肤 DIY 草稿。
4. 在 Windows 10/11 的 100% / 125% / 140% 缩放下检查全部导航、搜索、设置、下载和皮肤页面，没有文本遮挡。
5. 所有新增变更通过后再锁定源代码 SHA，生成独立 v0.9.44 正式版包及 SHA-256/Sigstore 资料并发布到 GitHub Releases。

## 使用者注意

已在旧版设置中明确关闭自动下载或自动切换的用户，需要到“设置 → 更新设置”重新启用。若下载中途断开或校验失败，启动器不得退出或切换。

# v0.9.36 正式版候选：国内外搜索与下载稳定性优化

目标：缩短 Minecraft Java 启动器的模组、光影、资源包、皮肤目录重复搜索等待时间；
改善中国内地/海外线路中的连接失败回退。**不承诺第三方服务在所有地区始终可用**。

## 已实现

- Modrinth 模组、光影、资源包及整合包的官方搜索数据，在同一电脑内存中
  **缓存最多 45 秒**。返回的原始 JSON 每次重新解析成独立结果，避免某个页面
  的筛选或修改污染另一页面。缓存最多保留 96 条，每条最多 512 KiB 字符。
- CurseForge（需用户自行启用 MCIM）公开搜索元数据同样复用短时缓存。
  仍使用合法第三方镜像的原有 API；不借用任何 CurseForge 私有 API 密钥。
- Mosaicary / DP-Plugins 的公开皮肤目录使用相同 45 秒内存缓存；
  缩略图最多同时处理 8 个下载，符合 PNG 文件头且小于 256 KiB 时
  暂存 8 分钟，最多 80 项。缩略图下载不等于下载受版权保护的皮肤原图。
- 当可信来源具有**既有且允许的**备用线路，首次请求的 HTTP 响应头等待
  最多使用 6 秒快速故障回退，单线路请求和传输中的空闲超时不会改变。
- 继续使用原有官方 Mojang、BMCLAPI、Modrinth，和用户可选启用的 MCIM，
  通过原有 HTTPS、哈希完整性检查、断点续传来源隔离及失败回滚保护。
- 所有缓存仅存在进程内存里，不持久保存个人搜索；不缓存账号令牌、
  Minecraft / 微软账号会话、玩家个人资料或未知第三方 URL。

## 设置建议

启动器「设置 → 网络/下载设置」：
- 中国大陆：**中国大陆优先**（适用于游戏文件的 BMCLAPI）
  并按自己对第三方 MCIM 服务的信任决定是否启用该开关。
- 海外：**海外优先**，先用官方服务，官方连接失败时允许既有备用源。
- **自动选择可用线路**会记住近期成功的备用线路；网络环境变化后自动
  重选，保存代理配置或切换线路不会跨模式读取旧缓存。
- 需要可自定义 HTTP 代理时，留空可使用 Windows 系统代理。
- 不要把「官方 API 不可用」、「皮肤作者未授权」、「CurseForge 内容下架」
  当成单纯的网络速度问题；授权、服务限流和资源可用性仍由第三方控制。

## 验收范围及仍存在的限制

GitHub Actions Windows CI 会执行现有 WPF 双发行形态、启动、下载、
皮肤、模组依赖、更新回滚和窗口复开等自检，并新增脱网模拟：
- 中国大陆/海外线路优先级、镜像认证接口拦截；
- 搜索缓存与网络模式、代理、MCIM 设置隔离；
- 真实模拟 HTTP 客户端重复搜索时只有一次网络请求；
- 缓存过期与大响应不可缓存；
- 有备用线路时首次连接超时降低、单线路维持原超时。

CI 模拟与海外 GitHub Runner 测试**不能替代中国内地运营商及海外
不同地区的真实网速验证**，因此不公布未经测量的加速百分比。
此次没有修改微软登录认证、账号 API，也没有增加不透明的公网代理源。
单文件 EXE、正常 ZIP、稳定版更新文件名和 v0.9.36 人工发布门禁保留。

v0.9.36 正式版只有在项目维护者完成真实设备验收并通过受控 GitHub
Release 工作流时才算发布；合并源代码与 CI 构建不代表已经发行正式版。

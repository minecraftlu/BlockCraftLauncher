# BlockCraft Launcher v0.9.59 RC1 · 游戏与模组下载指令

Windows 用户可下载并运行 `BlockCraftLauncher-v0.9.59-WPF-OneFile-Windows-x64.exe`。使用预览通道的玩家也可以在启动器内更新。

打开首页的「千问 AI 搜索」，输入指令后点「搜索」，或按 Ctrl + Enter。游戏版本及模组名称由启动器直接识别，无需配置 AI 密钥。

| 可以这样说 | 启动器会做什么 |
| --- | --- |
| 下载 Minecraft 1.21.1 | 查游戏版本目录，把指定版本加入下载任务 |
| 搜索游戏 1.20 | 打开游戏版本页并筛选列表，供你选择 |
| 给当前实例装钠 | 搜索 Sodium，按当前实例的游戏版本和加载器查找兼容正式版 |
| 在 Modrinth 搜索模组 Iris | 在指定来源显示搜索结果，供你查看文件 |
| 让千问帮我找个提高帧率的模组 | 使用已配置的百炼账号推荐一个项目，再打开模组目录供你选择安装 |

直接安装模组时，启动器需要匹配项目、实例和兼容文件。匹配有歧义时会保留搜索结果，可以在模组页选定目标和文件。已加入队列的任务可在「下载任务」查看进度或取消。CurseForge 的作者分发限制仍然生效。

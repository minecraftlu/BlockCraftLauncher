# CurseForge 官方 API（仅开发者本机）

**此功能不需要把 API Key 上传 GitHub，也不会将其编译进公共发布文件。**

你的 CurseForge 第三方 API 授权已获批。由于申请密钥是**个人私有凭据**，本项目只能在**开发者自己的受控 Windows 机器**从本地环境变量中读取它。未经 CurseForge 明确授权，不能把它嵌入对所有用户分发的 EXE。

## 设置方式（不要在 ChatGPT 或 GitHub 中公布密钥）

1. 在自己电脑上打开“系统属性 → 高级 → 环境变量”。
2. 在**当前用户的用户变量**新增 `BLOCKCRAFT_CURSEFORGE_API_KEY`，值为你有效的 CurseForge 私钥（不要在公共日志里打印）。
3. 完全关闭并重新启动 BlockCraft Launcher。
4. 打开「下载 → 模组下载」，把来源设为「CurseForge 官方」，选择目标实例、兼容文件版本，然后点击「安装所选版本」。
5. 在下载设置中启用 MCIM 后，可在同一页面主动选择「CurseForge · MCIM」。

**请优先撤销之前已在截图中出现的密钥并申请替换密钥。** 图片泄露过的旧密钥不建议长期使用。设置后不要分享带有密钥的截图。

## 技术与隐私限制

- 官方元数据请求只发往 `https://api.curseforge.com/v1/mods/...`，通过 `x-api-key` 标头认证。不会使用公共缓存或把私钥发送到第三方镜像。
- 官方 CDN 文件请求（`edge.forgecdn.net`）同样在必要时使用 `x-api-key`；禁用自动重定向，手动处理重定向，下载请求只向官方 Edge CDN 附加密钥。
- 文件 SHA-1 校验通过后才提交到实例目录；仍限制文件大小、重定向来源、加载器兼容性、依赖数量、文件名，安装失败清理临时文件。
- 未经允许的第三方分发内容不会绕过限制直接下载；受限制的内容须按作者授权使用。
- 此开发者私有 API Key 配置不适用于公开给其他玩家的启动器。若面向所有用户提供官方 CurseForge 搜索/下载，需要咨询 CurseForge 是否批准安全的服务端代理与分发架构，且必须遵守其第三方 API 许可条款。
- Windows 用户环境变量并非加密保险库，只适用于开发者自己控制的设备；不要将机器交给不受信任的人员使用。

适用于 Windows 10/11 x64（.NET Framework 4.8）。

- **单文件启动器更新到桌面。** 新版通过 SHA-256 校验并成功显示主窗口后，旧窗口才会关闭。更新器随后核对并删除本次启动的旧 EXE。启动器原本就在桌面时可原位升级，桌面上已有其他同名文件时自动改名。
- 校验失败或新版窗口提前退出时保留旧版。若旧文件正被占用，会显示其路径，方便稍后清理。
- 修复取消下载后立即重试时旧进度覆盖新任务、任务重复执行的问题。下载结束后，按钮状态和列表数量会及时刷新。

**下载与更新**  
只需下载 `BlockCraftLauncher-v0.9.53-WPF-OneFile-Windows-x64.exe`，双击运行。使用完整 ZIP 的用户请解压整个目录，再打开 `BlockCraftLauncher.Wpf.exe`。

已有启动器可在设置中选择「预览版」，保存后检查更新。从旧版升级到本版本时仍由旧版执行更新。**桌面迁移从 v0.9.53 RC1 单文件版发起的下一次更新开始生效。**

附件包含 SHA-256 清单和两个安装包的 Sigstore 签名。Windows 已验证下载目录到桌面的迁移、桌面原位升级、同名文件保护、新版启动失败时保留旧版，以及从桌面重新启动。[Windows 测试记录](https://github.com/minecraftlu/BlockCraftLauncher/actions/runs/45357556008)

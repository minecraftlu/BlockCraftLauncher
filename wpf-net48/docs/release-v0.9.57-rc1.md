# BlockCraft Launcher v0.9.57 RC1 测试版

Windows 用户可下载 `BlockCraftLauncher-v0.9.57-WPF-OneFile-Windows-x64.exe` 直接运行。已使用预览更新通道的用户可以在启动器中检查更新。

本版参考 PCL2 的菜单和按钮用词，将同一件事的不同操作放在同一页。原有功能可从以下位置进入。

| 想做什么 | 新入口 |
| --- | --- |
| 安装游戏，或导入本地文件 | 下载 → 安装游戏，选择「自动安装」或「本地导入」 |
| 搜索模组、选择版本及安装必需前置 | 下载 → 模组，在「来源」中选择 CurseForge 官方、Modrinth 等来源 |
| 下载皮肤，或使用已保存的皮肤 | 下载 → 皮肤管理，切换「下载皮肤」或「我的皮肤」 |
| 绘制、修改皮肤 | 更多 → 皮肤编辑 |
| 找服务器、使用收藏或查看局域网世界 | 联机 → 服务器，切换「收藏」「发现」或「局域网」 |
| 检查启动器更新、查看历史版本或切换预览通道 | 设置 → 启动器更新 |

CurseForge 公共模组服务已向玩家开放，无需填写 API Key。曾使用单独「CurseForge 官方」入口的玩家，在模组页选择同名来源即可继续下载。下载内容须符合作者的分发设置。

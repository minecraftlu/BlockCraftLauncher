# BlockCraft Launcher v0.9.44 RC1 · 测试版

目标：在新版本下载及 SHA-256 校验完成后，空闲时自动关闭旧版、原位置替换旧 EXE，再自动启动新版。保留移动硬盘同盘自定义目录设置、皮肤 360° 预览与已有功能，并改善 PCL2 风格信息架构。

发布门槛：完整 Windows CI/WPF 与 OneFile 构建、窗口与原位升级测试、Sigstore 验证。此版本仅供预览通道，不推送稳定版，也不宣称已在所有实际 Windows 网络环境验收。

历史升级路径：正式 v0.9.42 或预览 v0.9.43 RC3 均可在启动器“设置 → 更新设置 → 预览版”选择预览通道，手动检查并更新；旧版配置中的自动更新开关依然优先。

安全：请勿从非官方源下载安装包，EXE 只替换原启动器；世界、模组、存档与个人下载文件不在清理范围。

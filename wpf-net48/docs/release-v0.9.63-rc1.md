# BlockCraft Launcher v0.9.63 RC1 · 用指令下载

打开「更多 → 千问 AI 助手」，点「启动器下载指令」，在启动器的输入框里说出要下载的内容。可以按 Ctrl + Enter 发送。指定名称或游戏版本的指令无需下载千问模型，也无需填写 API Key。

| 试着输入 | 启动器会做什么 |
| --- | --- |
| 帮我找一个提升帧率的模组 | 打开模组目录，展示适合当前实例的项目供挑选 |
| 帮我装一个提升帧率的模组 | 在目录中选择项目，匹配当前实例的 Minecraft 版本和加载器，然后把兼容文件加入下载队列 |
| 给当前实例装钠 | 查找 Sodium，为当前兼容实例安装 |
| 下载 Minecraft 1.21.1 | 查找指定游戏版本，调用游戏安装流程 |
| 下载资源包 faithful-32x | 安装兼容的 Faithful 资源包到目标实例 |
| 下载光影 complementary-reimagined | 将对应的光影包下载到实例的 shaderpacks 文件夹 |
| 下载整合包 Fabulously Optimized | 查找并下载整合包，使用启动器的整合包导入流程创建独立实例 |

在「本地 AI」中，已准备好的 Qwen3.5-4B 可以根据用途挑选模组。请先选择要安装到的游戏实例。项目重名、没有兼容文件或无法确定目标时，启动器会显示可选项目或原因。下载进度和完成状态可在「下载任务」中查看。

打开「更多 → 千问 AI 助手」，就能在一个输入框里聊天、找模组和发送下载指令。默认使用本地千问 Qwen3.5-4B，也可以在输入框旁切换到云端百炼，继续同一段对话。切换时会保留草稿，以前保存的本地和云端会话都能在同一列表中找到。

### 试试下载指令

| 在对话框输入 | 启动器会做什么 |
| --- | --- |
| `从 Modrinth 下载模组 Sodium` | 为当前兼容实例查找 Sodium，把匹配的文件加入下载任务。 |
| `下载 Minecraft 1.21.1` | 将该游戏版本加入安装队列。 |
| `帮我找一个提升帧率的模组` | 使用已准备好的本地模型理解用途，从模组目录中推荐候选项目。 |
| `下载资源包 faithful-32x` | 为目标实例查找并安装兼容的资源包。 |

按 **Ctrl + Enter** 发送。指定项目名称或游戏版本的下载指令无需模型和 API Key。处理结果会记入当前对话，可在「下载任务」查看进度。图片创作、视频创作、模型准备和千问官网位于「工具」中。
